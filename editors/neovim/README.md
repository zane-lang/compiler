# Neovim

Neovim support is the [`zane-nvim`](https://github.com/zane-lang/zane-nvim)
plugin. It registers the Zane parser with nvim-treesitter, which downloads this
repository's `editors/tree-sitter-zane` grammar and this directory's
`queries/highlights.scm`, builds the parser and installs both.

`queries/highlights.scm` is generated by `python3 -m tools.grammar`: the shared
query from `editors/tree-sitter-zane/queries/highlights.scm` followed by
Neovim's own captures (`neovim_highlights` in `grammar/tree-sitter.coda`).
Those call the plugin's `zane-bound?` predicate with the grammar's binders and
the node types that can hold one, so the plugin itself holds nothing
grammar-specific. See [`grammar/README.md`](../../grammar/README.md).
